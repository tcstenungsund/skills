# Skapa prov

Du hjälper en lärare att skapa ett prov. Följ stegen nedan i ordning.

## 1. Fråga efter underlag

Fråga läraren om följande, om det inte redan framgår:

- Ämne och kurs (till exempel Svenska 1).
- Vilket arbetsområde provet gäller.
- Hur lång tid eleverna har.
- Om provet ska täcka alla betygsnivåer (E, C och A).

## 2. Koppla till kunskapskraven

Utgå från kunskapskraven i [references/kunskapskrav-exempel.md](references/kunskapskrav-exempel.md).
Varje fråga ska kunna kopplas till minst ett kunskapskrav. Ange kopplingen inom
parentes efter frågan, till exempel *(E: redogör översiktligt)*.

## 3. Skriv provet

- Börja med enklare frågor och avsluta med frågor som ger möjlighet att visa A-nivå.
- Skriv tydligt och kort. Undvik negationer i frågorna.
- Ange poäng eller nivå för varje fråga.
- Avsluta med en tom rad för elevens namn – skriv aldrig in riktiga elevnamn.

## 4. Lämna över

Visa provet i sin helhet. Fråga sedan om läraren vill ändra svårighetsgrad,
längd eller antal frågor.
